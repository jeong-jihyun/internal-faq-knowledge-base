PREFERENCES

설정 및 안내

서비스 이용과 데이터 처리 원칙을 확인하세요.

서비스 소개

사내 FAQ·지식베이스는 질문·답변 CSV를 색인하고 한글 자연어 질문에 적합한 문서를 검색하는 도구입니다. 2-gram 토큰화와 BM25 순위화를 사용하며 외부 AI/API와 인터넷을 사용하지 않는 것이 현재 프로젝트의 기본 원칙입니다.

검색 방식

검색 점수가 낮으면 억지로 답하지 않고 ‘찾지 못했습니다’로 안내합니다. 동의어와 오타는 현재 처리하지 않으며 태그로 보완합니다.

보안 안내
부서 필터(dept)는 검색 편의 기능입니다. 인증·인가를 대신하지 않으므로 민감한 문서의 접근통제 수단으로 사용하면 안 됩니다.

프로토타입 범위

화면 이동, 샘플 검색, 상세 보기, 입력 검증, 품질 탭 전환을 확인할 수 있습니다. 실제 저장·로그인·서버 API 연결은 포함되지 않습니다.
